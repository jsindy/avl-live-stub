# avl-live-stub

Public issue tracker for **AVL Live**.

The source code isn't in this repo. It's here so anyone can report bugs, request features, or ask questions.

## How to file an issue

1. Go to [Issues](https://github.com/jsindy/avl-live-stub/issues/new/choose).
2. Pick a template: **Bug report** or **Feature request**.
3. Fill it in with as much detail as you can.

Before opening a new issue, search the existing ones to check it hasn't already been reported.
